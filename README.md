## 📖 简介

**我爱八卦**是一款专业的周易六爻排盘系统，严格遵循传统算法，提供多种起卦方式，支持 Android 移动端。

### 🌟 核心特点
- ✅ **传统算法**：严格遵循《周易》18 变蓍草起卦法
- ✅ **多种起卦**：蓍草、金钱、梅花易数、手动起卦
- ✅ **专业排盘**：六亲、六神、世应爻、伏神完整显示
- ✅ **离线使用**：所有数据本地存储，无需联网
- ✅ **Android 支持**：完美适配移动端，界面美观

## 🚀 快速开始

### 环境要求
- Python 3.11+
- Kivy 2.3.0+
- Android 5.0+（如需移动端）

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行应用
```bash
python main.py
```

### 构建 Android APK
```bash
# 安装 buildozer
pip install buildozer

# 初始化（首次运行）
buildozer init

# 构建 APK
buildozer -v android debug

# 发布版本
buildozer -v android release
```

APK 文件位于：`bin/*.apk`

## 📐 算法说明

### 蓍草起卦法（18 变传统）

严格遵循《周易·系辞上传》第九章：

> "大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰。"

**操作流程**：
1. **初始**：49 根蓍草
2. **分二**：随机分成左右两堆
3. **挂一**：从右边取 1 根
4. **揲四**：左右每 4 根一组数
5. **归奇**：左右余数 + 挂一，从总数中减去
6. **三变**：重复 3 次，得到一爻
7. **六爻**：重复 6 次，得到完整卦象

**爻值计算**：
- 36 策 ÷ 4 = 9 → 老阳（⚊，可变）
- 32 策 ÷ 4 = 8 → 少阴（⚋，不变）
- 28 策 ÷ 4 = 7 → 少阳（⚊，不变）
- 24 策 ÷ 4 = 6 → 老阴（⚋，可变）

**概率分布**：
- 老阴（6）：1/8 = 12.5%
- 少阳（7）：3/8 = 37.5%
- 少阴（8）：3/8 = 37.5%
- 老阳（9）：1/8 = 12.5%

### 金钱起卦法

三枚铜钱摇卦，字为阴（2 分），背为阳（3 分）：

| 组合 | 总分 | 爻值 | 名称 | 符号 |
|------|------|------|------|------|
| 3 背 | 9 | 老阳 | 重爻 | ⚊ ○ |
| 2 背 1 字 | 7 | 少阳 | 单爻 | ⚊ |
| 1 背 2 字 | 8 | 少阴 | 拆爻 | ⚋ |
| 3 字 | 6 | 老阴 | 交爻 | ⚋ × |

### 梅花易数时间起卦

**公式**：
- 上卦 = (年支 + 月数 + 日数) % 8
- 下卦 = (年支 + 月数 + 日数 + 时支) % 8
- 动爻 = (年支 + 月数 + 日数 + 时支) % 6

**时支计算**：
- 子时（23-1 点）：1
- 丑时（1-3 点）：2
- ...
- 亥时（21-23 点）：12
- 公式：`(hour + 1) // 2`

**八卦数**：
- 乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8
- 余数为 0 时取 8（坤卦）

## ❓ 常见问题

### Q: 蓍草起卦和金钱起卦有什么区别？
A: 蓍草起卦是《周易》最传统的 18 变算法，仪式感强；金钱起卦是简化版，快速便捷。两者概率分布相同，结果准确度一致。

### Q: 老阳、老阴会变卦吗？
A: 是的。老阳（9）会变为阴爻，老阴（6）会变为阳爻，产生变卦。少阳（7）和少阴（8）不变。

### Q: 六亲是如何推算的？
A: 根据卦宫五行和爻位五行的生克关系：生我者父母，同我者兄弟，我生者子孙，我克者妻财，克我者官鬼。当前版本使用简化版逻辑，完整版纳甲系统将在 v1.3.0 实现。

### Q: 六神是如何排列的？
A: 根据起卦日的日干确定起始六神：甲乙日起青龙，丙丁日起朱雀，戊日起勾陈，己日起螣蛇，庚辛日起白虎，壬癸日起玄武。从初爻到上爻循环排列。

### Q: 如何在 Android 上使用？
A: 下载 APK 文件安装即可。如果遇闪退问题，请确保安装的是 v1.2.0+ 版本（已修复硬件加速问题）。

### Q: 数据来源是什么？
A: 卦辞、爻辞数据来自《周易》原文，六十四卦数据存储在 SQLite 数据库（data/gua_optimized.db）中，共 64 卦、386 爻。
