# 我爱八卦

一款简洁的金钱卦算卦软件，Android 平台。

## 功能特点

- 🎯 电脑起卦 - 随机生成卦象
- ✋ 手动起卦 - 手动输入卦象
- 📊 卦象显示 - 本卦、变卦、卦辞
- 📜 历史记录 - 保存所有起卦记录
- 💾 数据缓存 - 提高查询效率

## 安装

### Android APK

1. 下载 APK 文件
2. 在 Android 设备上安装
3. 打开应用开始使用

## 使用

1. 选择起卦方式（电脑起卦或手动起卦）
2. 输入卦象信息
3. 查看卦象解释
4. 历史记录随时查看

## 技术栈

- **Kivy** - 跨平台 UI 框架
- **Python 3.11** - 编程语言
- **Buildozer** - Android 打包工具

## 开发

### 环境要求

- Python 3.11+
- Kivy 2.1.0
- Buildozer 1.5.0

### 本地运行

```bash
pip install -r requirements.txt
python main.py
```

### 构建 APK

```bash
buildozer android debug
```
